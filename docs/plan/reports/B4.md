## What was built

| Piece | Where | What it does |
|---|---|---|
| Locator | `services/evidence_api/locator.py` | Finds the segment and record holding an `event_uid`, newest segment first, bounded by `EVIDENCE_MAX_SEGMENTS_SCANNED` |
| Verifier | `evidence_api/verifier.py` | The eight steps, each reusing the primitive that produced the artefact: `fetch_raw`, `decrypt_segment`, `hash_raw`, `chain_walk`, `segment_digest`, `merkle_inclusion`, `root_signature`, `immudb_verified`. A step that cannot run is reported failed with its reason, never skipped |
| Export | `evidence_api/export.py` + `verify_template.py` | The auditor ZIP: raw bytes, envelope, proof, signed root, pubkey, a dependency-free `verify.py`, and the BSA 2023 §63 technical section |
| HTTP surface | `evidence_api/app.py` | `/lineage/{overview,sources,search,events,templates,stream}`, `/evidence/{verify,export,roots,pubkey}`, dual-spelled so both the contract path and the Caddy-stripped path resolve |
