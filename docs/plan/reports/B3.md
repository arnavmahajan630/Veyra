## What was built

| Piece | Where | What it does |
|---|---|---|
| Merkle tree | `packages/veyra_evidence/merkle.py` | `inclusion_proof` / `verify_inclusion` over segment digests, single-leaf windows included |
| Signed roots | `veyra_evidence/ledger.py` | `LedgerEntry`, canonical bytes, `payload_sha256`, the `prev_signed_sha256` chain from `GENESIS_PREV`, and `ledger.ndjson` |
| Integrity service | `services/integrity/` | Closes a window every `MERKLE_WINDOW_SECONDS`, builds the tree over that window's segments, signs the root (Ed25519) and appends it |
| Ledger audit | `tools/ledger_audit.py` | Per-entry checks: payload schema, signature, prev-hash link, window ordering; PASS/FAIL with a finding per check |
| immudb | `compose/docker-compose.yml` + state | **Prototype only.** The container runs and a database name is recorded; roots are not anchored |

## How to run and test

```bash
uv run pytest services/integrity packages/veyra_evidence -q
uv run python tools/ledger_audit.py
```
