## What was built

**`services/drift_worker`**

| Module | What it does |
|---|---|
| `groups.py` | groups DLQ records by `(source_id, template_sig)`: count, first/last seen, up to 5 distinct masked samples, and the event uid each came from |
| `miners.py` | one Drain3 `TemplateMiner` per source, persisted to `data/state/drain3/<source>.json`. It masks `key=`/`key:` values and IPv4s first, so T3 clusters to `user=<*> FAILED login from <*> via <*> attempts:<*>`. |
| `worker.py` | emits once `count ≥ VEYRA_DRIFT_MIN_CLUSTER`, debounced per group (`VEYRA_DRIFT_DEBOUNCE_MS`); a forced flush; a failed post is retried on the next tick; checkpoint (groups plus Drain3 state) and reset |
| `app.py`, `__main__.py` | `POST /flush`, `POST /reset`, `GET /groups` on `:8206`; the `dlq` consumer (group `drift-worker`) commits offsets only after a checkpoint |

Compose service `drift-worker`, profile `c3`.

**control-api:** `drift.py` and `routes_drift.py`:
- `/internal/drift` upserts;
- `GET /drift`, `GET /drift/{id}`, `POST /drift/{id}/dismiss`;
- an item resolves when the source's active version covers it (at upsert, and after promote or rollback);

## Deviations from the phase file

1. **Items resolve when the active version covers them, not the canary** (TC24). AC2 says "after promote", and resolving at canary would empty the inbox mid-review.
2. **Restart strategy: persisted counts** (TC25), the option C3 AC3 offers.
3. **Unregistered traffic is not drift** (TC31).
4. **Generic packs map only the fields every event carries** (TC29). The engine makes an event that lacks a mapped field tier 2.

## Known issues / risks

1. **A crash between a checkpoint and the offset commit** re-counts at most one checkpoint interval (5 s) of DLQ records.
2. **drain3 0.9.11 pins old jsonpickle and cachetools versions.** They work on 3.12; watch for conflicts if another package needs newer ones.
3. **The seeded `linux_sshd@1` still misses 13 sshd shapes**, which will appear in the demo's drift inbox. The owner decides whether the seed takes the library version (that needs A to regenerate their sshd snapshot).
