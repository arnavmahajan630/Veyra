## How to run and test

```bash
make console-mock        # http://localhost:5173, fixtures, no backend; sign in as admin@veyra / veyra-demo
make console-test        # 126 unit tests (vitest + Testing Library + MSW)
make console-contrast    # WCAG AA check of the tokens
make console-e2e         # Playwright smoke (downloads Chromium once: npx playwright install chromium)
make console-build       # static bundle into console/dist, served by caddy on :8080
make console-dev         # Vite on :5173 with /api proxied to caddy :8080 (needs `make up`)
```

Node 25 with npm 11 is required. Vite 7 refuses Node below 20.19, and npm 10.8 crashes resolving jsdom's optional `canvas` peer.

## Deviations from the phase file

1. **API types are hand-written, not generated** (TC14). Neither OpenAPI document is published yet (control-api's needs `root_path`; B4 doesn't exist). `make console-types` with `openapi-typescript` comes once both exist.
2. **Fonts come from `@fontsource/*`**, bundled by Vite into `dist/assets/`, rather than hand-copied into `console/public/fonts/`. They're still self-hosted and OFL-licensed.
3. **In dev mode, Vite proxies `/api` to Caddy** (TC13), rather than Caddy fronting Vite. The browser still sees one origin, so D16 holds without the Caddyfile's unimplemented `CONSOLE_DEV_UPSTREAM`.
4. **The source drawer links to Drift filtered by source**, but doesn't list recent DLQ template sigs with counts. That list needs the drift inbox page (C6); C6 can fill the drawer section from `GET /drift?source_id=`.
5. **Toolchain:** built and tested with Node 25.9.0 / npm 11.20.0; the laptop pin is 25.2.1 / 11.7.0. Both satisfy `engines: >=25`, and `package-lock.json` fixes every library version.

## Design note (default-avoidance review)

- Palette: cool off-white paper and an indigo thread, not cream and terracotta, and no dark theme with an acid accent.
- No cards: tables and panes are separated only by hairline rules, with zero radius and no shadows. Pipeline stages are ruled boxes, not raised cards.
- No eyebrow labels and no all-caps: every heading is sentence case, straight from `t()`.
- No middle-dot meta strings: the user menu stacks the email over the role.
- Buttons say what happens ("Issue a new key", "Switch to approver@veyra", "Sign out"); none carry arrow suffixes.
- One animation only: the thread's 180 ms path draw, off under reduced motion. Pipeline lines stay still (their thickness follows EPS); only the numbers change.
- Mono appears only for ids, keys, contract refs and raw bytes; every label is Mukta.
- Tier colours never carry text. They are swatches and bars with ink labels beside them, and the contrast check pairs them at 3:1.
- The silent-source alert is an amber row plus words ("No events for 1m 20s"), not colour alone.
- Checked at 1920×1080, 1366×768, 1280×720 and 1024×768. Below 1280 px (projectors) the rail starts collapsed and the header's field captions become screen-reader-only, so the header stays on one line and the pipeline fits without scrolling. At 1366 and below, the Evidence and Delivery panels fall below the fold on Overview; the drawer covers the right half of the table, as intended.
- The pipeline's main path (sources → edge → Kafka → normalizer → router → Wazuh) is one straight line, with the vault and lineage index branching after Kafka, as C5 draws it.
- The tier bar draws 10-second columns (90 over 15 minutes). Their boundaries follow the sample count, so each second only the newest column changes, and the picture steps left once every 10 s.

## Known issues / risks

1. **The tier bar opens full only if evidence-api sends `tier_history`** (optional, in the REQUEST to B). Without it, the bar fills from the right one second at a time. It keeps collecting on every page, though, so only the first 15 minutes after opening the console are thin. The mock sends a history.
2. **The Wazuh stage shows the Wazuh route's lag**, not a count; IF-API-EVIDENCE has no Wazuh-side count.
3. **`hi.json` hasn't been reviewed by a Hindi reader yet** (C5 asks for this before the demo).
4. **`dist/mockServiceWorker.js` ships in the bundle** because Vite copies `public/`. It's inert: nothing registers it outside mock mode.
5. **The live halves of AC1 and AC2 are untested**: no evidence-api exists yet, and the console hasn't been served through Caddy with the stack up.
6. **Mock mode depends on the MSW service worker.** A browser that stops an idle worker would silently send requests past the mocks; the page now re-announces itself to the worker every 3 s and on focus. Avoid Ctrl+Shift+R in mock mode (a hard reload bypasses service workers).
