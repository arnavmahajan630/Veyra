## What was built

**`veyra_contracts.drafting`**

| Module | What it does |
|---|---|
| `classify.py` | envelope layers via A4's detectors (syslog, then CEF / LEEF / JSON text field) |
| `request.py` | IF-LLM-DRAFT request; users and emails masked in the prompt only |
| `schema.py` | closed vocabulary: token ids or enum consts |
| `heuristic.py` | deterministic mapping from token kinds and the word before them |
| `ollama.py` | `/api/chat`, temperature 0, seed 7, one retry, then `DraftFailed` |
| `cache.py`, `drafter.py` | `live`, `cache`, `live_then_cache`, `heuristic`, with a source badge |
| `generalize.py` | token ids → pattern → contract YAML |
| `verify.py` | compile, provenance, types |

**control-api**

- `POST /drift/{id}/draft` starts a draft and does not submit. `GET` / `PATCH /drafts/{id}`, `POST /drafts/{id}/submit` (the submitter is the author).
- `POST /onboarding/analyze` streams SSE: classification, templates, library, draft, done, error.
- Auto-draft, when `VEYRA_DRIFT_AUTODRAFT` is on, runs as `drift-worker`.

**Bench (not measured)**

`tools/bench/llm_bench.py` with `build`, `run`, `warm`, `seed`. Make targets `llm-warm`, `bench-llm`, `llm-cache-seed`. Cases come from the registry library packs plus `bench/llm_golden/extra.json` (authsrv T1, T2, T3).

## Deviations from the phase file

1. **Onboarding groups by token skeleton, not raw `template_sig`.** IF-TEMPLATE-SIG leaves usernames literal, so three session lines would be three groups. The sig stored on a group is still `template_sig(contract_id, first line)` (TC32).
2. **A tail the samples disagree on becomes `<*>`.** `312s` / `319s` / `326s` is not one token, so the pattern keeps `after` and wildcards the duration.
3. **Verification checks the template a sample matched.** A second template's fields are not missing-span failures.
4. **Live bench not run.** `make llm-cache-seed` is in the tree and still needs Ollama.

## Known limit (AC3)

Swapping the src and dst tokens keeps provenance green: both spans are real bytes. The backtest is what shows the fields moved. A const the enums do not contain is rejected with 422. Human review stays because a located value can still be the wrong field.
