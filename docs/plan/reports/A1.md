- **Date / author (human + agent):** 2026-09-27, Person A (Arnav) with Claude Opus 5
- **Branch / PR:** committed directly to `main` (`865d6e0`)
- **Contracts version at start → end:** v1.1 → **v1.2** (clarification: IF-INVENTORY reload mechanism)

## What was built

`edge/vector/vector.toml.tmpl` plus `edge/render.py` render `vector-dmz.toml` and
`vector-core.toml` (`make edge-render`, also run by `make up`). Rendering rather than letting
Vector interpolate `${VAR}` means the effective limits sit in a file that can be diffed,
`vector validate`d and unit-tested — and `make edge-check` fails if a rendered file is stale.

Per zone the pipeline is: `socket` UDP + TCP sources (`decoding.codec = "bytes"`, nothing is
parsed at the edge) → `pre_udp` / `pre_tcp` markers → `tcp_join` (`reduce`) → `stamp` (the
VRL that builds IF-ENVELOPE) → `kafka` sink to `raw.<vendor>` with a disk buffer.

**Stamping (P1).** Order as A1 specifies: bytes → byte length → truncation flag → SHA-256 →
base64 → UUIDv7 → nanosecond `received_time` → per-zone constants. The envelope is built as a
fresh object so no Vector metadata leaks onto the wire and the field set matches
`veyra_common.models.Envelope` exactly (which is `extra="forbid"`).

**Framing.** A UDP datagram is one event. TCP is newline-delimited, and a `reduce` grouped by
`(peer_host, peer_port)` joins continuation lines — leading whitespace, or `at ` for JVM stack
frames — flushing on the next non-continuation line or after `VEYRA_EDGE_MULTILINE_FLUSH_MS`.
Joined events carry `framing.method = "multiline_join"`, `parts = n`, and the original bytes
joined with a single `\n`.

**Resolution.** The syslog host is pulled out of the first 256 bytes (RFC 5424 pattern first,
then 3164), then two enrichment lookups: `(listener, peer_ip)`, then `(listener, syslog_host)`.
A miss yields `unregistered` / `unassigned` / `unregistered` on `raw.unregistered` — an
outcome, not an error (P2).

**Tests.** `edge/vector/unit_tests.toml` — 7 Vector-native config tests (`make edge-test`) that
run the real VRL with no sockets; `tests/int/test_edge.py` — 10 integration tests through real
sockets and real Kafka; `tests/int/test_edge_outage.py` — the two slow ones (full-size AC1 and
the Kafka outage), split out behind a new `slow` marker and `make test-int-slow`.

## Spike results (the phase's first task)

Pinned Vector `0.58.0-debian` has everything A1 needs, so **the Python edge-stamp sidecar
fallback is not used and no DEVIATION is logged**:

| Function | Available | Note |
|---|---|---|
| `sha2(raw, variant: "SHA-256")` | yes | lowercase hex, matches `hashlib.sha256().hexdigest()` |
| `encode_base64` / `decode_base64!` | yes | round-trips the exact bytes |
| `uuid_v7()` | yes | so `event_uid` sorts by creation time; no `uuid_v4` downgrade |
| `get_enrichment_table_record` | yes | file enrichment table, CSV encoding |
| `format_timestamp!(now(), "%Y-%m-%dT%H:%M:%S%.9fZ")` | yes | nanosecond precision |

**The important one:** `length()` on a string is the **byte** length, `strlen()` is characters.
A Devanagari test line is 42 characters and 50 bytes. Recording characters would corrupt every
byte offset in `ulpf.field_offsets` downstream (P4), so `length()` is mandatory and a config
unit test pins both numbers.

## Deviations from the phase file

1. **`reload.stamp` is not the trigger.** The phase file assumed a stamp file included in the
   watched config would be needed; measurement says Vector watches the CSV directly. The file
   is kept as an inert hook in case that changes, and C1 is told it is optional.
2. **No `[[tests]]` inside the rendered config.** Vector unit tests live in a separate
   `edge/vector/unit_tests.toml` passed alongside the config, so the rendered file stays
   exactly what production runs.
3. **`VEYRA_EDGE_BUFFER_BYTES` floor.** Vector refuses a disk buffer below 256 MiB + 32 B;
   `render.py` clamps to that and the profiles now carry `268435488` with a comment. The old
   `268435456` crash-looped the edge.
4. **The kafka sink healthcheck is disabled.** The topic is templated per vendor, so Vector
   cannot resolve it without an event and logs `Could not generate topic for healthcheck`
   forever. Container liveness uses Vector's own API instead.
5. **Slow tests are split out** behind a `slow` marker (`make test-int-slow`) so `make test-int`
   stays under two minutes.

## Known issues / risks

1. **A config reload briefly drops in-flight events.** `--watch-config` tears the topology down
   and rebuilds it; an event arriving in that window is lost. Observed once during development.
   Mitigations: the integration tests retry a send before failing, C1 should batch inventory
   writes, and the demo's onboarding path (Beat 2) uses the HTTP gateway, which needs no
   inventory change at all.
2. **The last TCP event of an idle connection waits for the reducer to expire**
   (`VEYRA_EDGE_MULTILINE_FLUSH_MS`, 500 ms on laptop). Correct and bounded, but it means a
   single-event assertion on TCP must allow ~1 s.
3. **`peer_ip` from the host is the docker gateway** (172.20.0.1), so host-side tests resolve by
   `syslog_host`, not by IP. Testing the `peer_ip` path needs a container with a static address
   on `veyra_net` — the demo senders (B7) will have one.
4. **Vector's `reduce` never flushed on idle in one early experiment.** It does flush (verified
   in isolation and in the tests); the earlier observation was a topology reload in progress. If
   it ever reappears, check for a reload rather than suspecting the reducer.

## Notes for downstream phases

**A2 (gateway):** `veyra_common.envelope.stamp` and `framing.split_lines` are now the shared
contract with this phase, and `test_edge_and_stamp_agree_on_the_same_bytes` locks them together
— run it after touching either. Reuse `framing.split_lines` for the HEC raw endpoint rather than
re-implementing the continuation rule.

**A3 (engine):** envelopes on `raw.*` now carry real `vendor` values (`linux`, `acme_ngfw`,
`custom`, `unregistered`), so the normalizer's `^raw\..*` pattern subscription sees several
topics; `ulpf.raw_ref` must be filled from the Kafka coordinates of the message being processed,
not from the envelope. Unregistered events arrive with `contract = null` — that is the tier-3
path A4 will exercise.

**A6 (router) and anyone writing integration tests:** copy the two patterns from
`tests/int/test_edge.py` — tag payloads with a unique marker, and pin the consumer to captured
end offsets with `assign()` instead of `subscribe()`. A pattern subscription with
`auto.offset.reset=latest` can rebalance after your send and skip the event; that cost an hour
here.

**@B / @C (via the changelog):** `reload.stamp` is optional on Vector 0.58 (C1), and a reload
costs in-flight events, so batch inventory writes.
