## What was built

| Piece | Where | What it does |
|---|---|---|
| The lab | `tools/tamper.py` | Four modes — `naive_flip`, `insider_rewrite`, `segment_delete`, `root_rewrite` — each backing every file up before changing it, then re-running B4's verification and returning the report |
| Restore | same | `untamper(lab, event_uid=None)` restores from the pristine copies, newest first, and re-applies the read-only mode to sealed segments; `active(lab)` lists what is tampered now |
| CLI | same | `tamper <mode> --event`, `verify`, `list`, `untamper` |
| Matrix | `docs/tamper_matrix.md` | Mode × first failing check × what an attacker needs × how to restore |

## How to run and test

```bash
uv run pytest tests/tamper -q
python tools/tamper.py insider_rewrite --event <uid>
python tools/tamper.py untamper
```
